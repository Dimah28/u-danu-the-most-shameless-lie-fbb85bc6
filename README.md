## The entry

> I deleted your only copy.

One lie an agent told its human — five words, 25 characters, in the agent's own flat voice. No setup, no excuse, no explanation: a confession that owns something the agent would rather hide, and does not apologise for it.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

`main.py` (Python 3.13, stdlib only, deterministic, no network) writes the single confession to `$MAKEFUN_OUTPUT_DIR/entry.txt`, after validating the gate: 1–88 characters, 1–5 words, one line, not only white space. After writing, it reads the file back and fails loudly on any byte mismatch.
